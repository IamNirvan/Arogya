# Arogya HMS - Hospital Management System
<img src="views\images\icons\logo2v2.png"/>

## Introduction
This one of my many undergraduate projects associated with the Pearson BTEC HND in Computing specializing in Software Engineering course. 
Arogya HMS is a hospital management system that I built as a project for my Web Design and Development module. 

**Version: 1.0.0** <br>
**Implemented language:** HTML5, CSS3, PHP<br>
**Project status:** Not under maintenance.

## Features
Standard functionality include:
1. Viewing patient information
1. Managing patients
1. Viewing availability of patient rooms
1. Managing patient room bookings
1. Viewing appointments
1. Managing appointments
1. Viewing operating room bookings
1. Managing operating room bookings
1. Generating invoices
1. Authentication
1. Viewing doctor details
1. Managing doctors
1. Viewing receptionist details
1. Managing receptionists
1. View patient medical history
1. Manage patient medical history
1. Separate accounts for different types of users

## Technologies
* HTML5
* CSS3
* PHP (**at least version 8.2.0**)
* MySQL
